# UDC licensing and hierarchy data

CroUDC separates bibliographic-source rights from UDC-scheme rights.

## UDC Summary

The openly reusable UDC Summary is published by the UDC Consortium under CC BY-SA 3.0. A machine-readable export is being requested for the hierarchy-aware analysis.

A verified export is **not included in this repository yet**.

## Full UDC MRF

The full UDC Master Reference File is proprietary/licensed material and is not redistributed here.

## Repository policy

Do not commit:

- the full UDC MRF;
- an unverified scraped pseudo-hierarchy;
- third-party UDC exports unless their licence and attribution requirements have been checked.

The hierarchy layer will not use prefix heuristics as if they were the official UDC hierarchy.
